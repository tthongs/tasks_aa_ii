    UUID=D494677F9467634A /mnt/OS ntfs-3g defaults,uid=1000,gid=1000,dmask=022,fmask=133,nofail,x-systemd.device-timeout=10s,windows_names 0 0

  Key Option Explanation:

    * ntfs-3g               : Uses full userspace NTFS driver.
    * uid=1000,gid=1000     : Grants full read/write ownership to user `tthh0ngs`.
    * dmask=022,fmask=133   : Sets safe default permissions (directories: 755, files: 644).
    * nofail                : CRITICAL: Prevents system boot failure/hang if disk fails to mount.
    * x-systemd.device-timeout=10s : Limits mount wait duration during boot to 10 seconds.
    * windows_names         : Prevents creating file names illegal in Windows NTFS.
