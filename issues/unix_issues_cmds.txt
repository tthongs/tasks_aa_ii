This file documents all Unix shell commands used across the resolution of

===============================================================================
1. SYSTEM DIAGNOSTICS & HARDWARE INSPECTION
===============================================================================

-------------------------------------------------------------------------------
1.1 uname - Kernel Information
-------------------------------------------------------------------------------
Command:
  uname -a

Context & Purpose:
  Used in ISSUE_011 / REPORT_003 to identify the operating system, hostname, 
  kernel release version, and machine architecture before performing hardware 
  driver checks.

Command Breakdown:
  -a : Print all system information (kernel name, nodename, release, version, 
       machine, processor, hardware platform, and OS).

-------------------------------------------------------------------------------
1.2 lspci - PCI Bus & Hardware Device Inspection
-------------------------------------------------------------------------------
Command:
  lspci -nnk | grep -A 3 -i audio

Context & Purpose:
  Used to identify all PCI audio hardware, vendor/device IDs, and currently 
  loaded kernel drivers (e.g., Intel Raptor Lake cAVS and NVIDIA GPU Audio).

Command Breakdown:
  lspci     : List all PCI devices connected to the motherboard.
  -nn       : Display both vendor/device names and hexadecimal IDs [8086:51ca].
  -k        : Show kernel drivers handling each device and kernel modules.
  grep -A 3 : Search for "audio" (case-insensitive) and print 3 lines after match.

-------------------------------------------------------------------------------
1.3 lsusb & lsblk & blkid - USB, Block Devices, and UUID Identification
-------------------------------------------------------------------------------
Commands:
  lsusb
  lsblk -f
  blkid /dev/sda1

Context & Purpose:
  Used in ISSUE_007 (SSD Mount) and ISSUE_011 (Hardware Audit) to discover USB 
  peripherals and locate drive UUIDs for stable mount point configurations.

Command Breakdown:
  lsusb    : List USB buses and attached devices (e.g., RTL9210 NVMe Enclosure).
  lsblk -f : List block devices in a tree structure with filesystem types and UUIDs.
  blkid    : Print block device attributes (UUID, LABEL, TYPE) for fstab entries.

-------------------------------------------------------------------------------
1.4 journalctl & dmesg - System Log & Kernel Buffer Inspection
-------------------------------------------------------------------------------
Commands:
  journalctl -b -k | grep -iE 'sof|dmic|audio|hda'
  journalctl -p 3 -b 0 --no-pager
  journalctl --vacuum-time=2d

Context & Purpose:
  Used across ISSUE_003 (Boot Bottlenecks), ISSUE_007 (SSD disconnects), and 
  ISSUE_009 (Bluetooth Firmware) to inspect system errors and clean up log bloat.

Command Breakdown:
  -b / -b 0  : Filter logs to current boot session.
  -k         : Filter to kernel log messages only (dmesg equivalent).
  -p 3       : Filter by priority level 3 (ERRORS) up to 0 (EMERGENCY).
  --no-pager : Output directly to terminal without piping to less/cat.
  --vacuum-time=2d : Delete journal log files older than 2 days to free disk space.

2. AUDIO & MICROPHONE DRIVER CALIBRATION
===============================================================================

-------------------------------------------------------------------------------
2.1 amixer - ALSA Hardware Mixer Controls
-------------------------------------------------------------------------------
Commands:
  amixer -c 0 scontrols
  amixer -c 0 sset 'Internal Mic Boost' 1
  amixer -c 0 sset 'Capture' 65%

Context & Purpose:
  Used in ISSUE_011 / REPORT_003 to fix severe microphone static noise caused by 
  preamp gain overload (+60dB combined gain).

Command Breakdown:
  -c 0    : Select ALSA sound card 0 (Realtek ALC256).
  scontrols : List all simple mixer controls available on the sound card.
  sset    : Set a simple mixer control level.
  'Internal Mic Boost' 1 : Lower hardware mic boost from +30dB (Level 3) to +10dB (Level 1).
  'Capture' 65%          : Set capture gain to 65% (+13.50dB).

-------------------------------------------------------------------------------
2.2 arecord - Sound Recording Diagnostic
-------------------------------------------------------------------------------
Command:
  arecord -d 2 -f S16_LE -r 44100 /tmp/test_mic.wav

Context & Purpose:
  Used in ISSUE_011 to record raw audio samples from card 0 for waveform amplitude 
  analysis using Python.

Command Breakdown:
  -d 2      : Record duration of 2 seconds.
  -f S16_LE : Format: Signed 16-bit Little Endian PCM.
  -r 44100  : Sample rate: 44.1 kHz (CD quality).

-------------------------------------------------------------------------------
2.3 alsactl - ALSA Driver State Persistence
-------------------------------------------------------------------------------
Command:
  sudo alsactl store

Context & Purpose:
  Saves the calibrated hardware mixer controls to `/var/lib/alsa/asound.state` 
  so audio settings persist automatically across system reboots.

Command Breakdown:
  store : Read current driver mixer levels and save them to state file.

4.1 umount - Unmounting Stale Drives
-------------------------------------------------------------------------------
Command:

Context & Purpose:
  Used in ISSUE_007 to clear stale, dangling mount points caused by external USB

4.2 udevadm - Dynamic Device Manager Control
-------------------------------------------------------------------------------
Command:
  sudo udevadm control --reload && sudo udevadm trigger

Context & Purpose:
  Used in ISSUE_007 to reload custom udev rules (`/etc/udev/rules.d/`) for

Command Breakdown:

4.3 find & sed - Automated File Search and In-Place Editing
-------------------------------------------------------------------------------
Commands:
  find ~/.config/google-chrome/ -name "Preferences" -exec sed -i 's/"exit_type":"Crashed"/"exit_type":"Normal"/g' {} +
  find ~/.config/google-chrome/ -name "SingletonLock" -delete

Context & Purpose:
  Used in ISSUE_002 to fix Chrome/Brave "didn't shut down properly" restore prompts 
  by resetting crash flags and deleting stale lock files.

Command Breakdown:
  find <dir>    : Search directory recursively.
  -name <pattern>: Match files by filename pattern.
  -exec ... {} + : Execute command on matching files in batch mode.
  sed -i        : In-place text editing (search and replace matching strings).
  -delete       : Delete matching files directly.

-------------------------------------------------------------------------------

  grep "set timeout=" ...           : Verifies active timeout setting in compiled config.

SECTION 12: CUSTOM GRUB MENU ENTRIES (POWER OFF)
===============================================================================

-------------------------------------------------------------------------------
12.1 /etc/grub.d/99_poweroff - Adding Power Off Option to GRUB Menu
-------------------------------------------------------------------------------
Commands:
  sudo cat << "EOF" > /etc/grub.d/99_poweroff
  #!/bin/sh
  exec tail -n +3 $0
  menuentry 'Power Off' --class shutdown {
      halt
  }
  EOF
  sudo chmod +x /etc/grub.d/99_poweroff
  sudo grub-mkconfig -o /boot/grub/grub.cfg
  sudo grep -A 5 "menuentry 'Power Off'" /boot/grub/grub.cfg

Context & Purpose:
  Creates an executable custom GRUB entry script numbered `99_poweroff` so that
  the 'Power Off' menu entry appears cleanly at the end of the GRUB menu.

Command Breakdown:
  /etc/grub.d/99_poweroff : Script file path (#99 guarantees bottom position in GRUB list).
  chmod +x                : Marks script executable so `grub-mkconfig` processes it.
  halt                    : Built-in GRUB shell command that powers off hardware immediately.
